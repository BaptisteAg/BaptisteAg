# Baptiste Ageron

**Développeur full stack chez IDEAGENCY.** Je travaille sur des applications web,
des intégrations et des outils qui répondent à des besoins concrets.

Mes projets explorent toute la chaîne : une interface compréhensible, des données
structurées, des services backend et une mise en œuvre documentée. Je m'intéresse
aussi aux outils Linux et à la conception matérielle, lorsque le logiciel doit
s'intégrer à un environnement réel.

## Projets sélectionnés

- **[CheckAdresse Lyon](https://github.com/BaptisteAg/checkadresse-lyon-portfolio)** :
  conception d'un produit web pour comprendre le contexte d'une adresse avant
  un achat immobilier. Next.js, React, Django, PostGIS et traitements asynchrones.
- **[Strapi 4 FTP Provider](https://github.com/BaptisteAg/strapi4-ftp-provider)** :
  intégration d'un stockage FTP à la bibliothèque média de Strapi, avec configuration
  et exemples d'utilisation. JavaScript et Node.js.
- **[Brightness DDC Control](https://github.com/BaptisteAg/brightness-ddc-control)** :
  extension GNOME qui pilote la luminosité matérielle des écrans via DDC/CI.
  JavaScript, interface système et outils Linux.
- **[Station de cuisine](https://github.com/BaptisteAg/station-portfolio)** :
  prototype numérique d'une station à écran e-paper, avec boîtier paramétrique
  conçu en Python et CadQuery. Le montage physique et le firmware restent à réaliser.

## Compétences et approche

Frontend avec React, Next.js et TypeScript ; backend avec Django, Laravel et
Node.js ; données relationnelles et géographiques avec PostgreSQL et PostGIS.
Mes réalisations touchent également aux API, aux traitements asynchrones, à
la configuration Linux et à la CAO programmable.

Les présentations distinguent les fonctionnalités implémentées, les observations
locales et les validations encore nécessaires. Elles expliquent les choix
techniques et les limites, pour permettre de comprendre le projet avant de
parcourir le code ou ses documents.
